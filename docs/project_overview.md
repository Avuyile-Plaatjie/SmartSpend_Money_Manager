# Project overview

**Problem:** bank statements are long lists of transactions that can be hard to interpret.

**Solution:** import a statement, review and correct transactions, then view an income/expense summary, category breakdown and practical budgeting ideas.

**Intended users:** students, employed people and anyone trying to understand personal cash flow.

**User journey:** upload records → review classification → generate report → explore categories → choose a realistic action.

**Limitations:** formats differ; recommendations are general and users must verify all values.
